答案
决策
统一视角：通用智能体框架里常说的「记忆」「工具」「知识库」，在本框架下都是 Context 的不同来源—— 知识库是预加载的长期记忆，工具调用产出的是情境数据，对话历史积累的是工作记忆。 LLM 读取的始终是统一的 Context 空间，并不区分这些数据的来源。

当前落地难点

动态上下文存在两类系统性缺口，制约了诊断智能体在真实生产环境中的落地效果

静态上下文（知识库）与监控系统查询已基本可用，但动态上下文仍存在两类缺口： 一是生产环境工具访问受限，导致部分根因无法通过实验验证； 二是人员间多模态交流内容无法进入 Context，形成重要的信息盲区。
①
生产环境工具访问受限
部分根因只能通过在生产环境多次试验才能确认，而当前 SRE 规范几乎不允许在线上执行有副作用的操作
✅ 当前可获取
  • 监控系统查询
  • 日志检索分析
  • 只读 /proc 读取
  • 历史快照 · SAR
  • 源码 · Commit 检索
  • kdump vmcore 分析
